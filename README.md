# Brew & Bean — Mini Coffee E-commerce

A responsive coffee storefront built with HTML, CSS, and vanilla JavaScript.

## Features
- Product catalog with category filters and live search
- Shopping bag with quantity controls and remove actions
- Automatic subtotal and free-delivery progress indicator
- Wishlist saved in local storage
- Demo checkout form with order confirmation
- Newsletter sign-up interaction
- Responsive desktop and mobile layouts
- No build tools or API keys required

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in your browser, or use the VS Code **Live Server** extension.
3. Internet access is needed for Google Fonts and the Unsplash product photos.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the root of your repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages workflow to finish.

## Note
This is a front-end demo. The checkout does not take real payments and does not submit orders to a server. A real store would need a backend, secure payment provider, order storage, and privacy/security review.
